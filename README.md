## 주요 기능

### 1. 회원가입 및 로그인

#### 개요
- 이메일 또는 닉네임 기반 회원가입 및 로그인 지원
- OAuth 2.0 로그인 (Kakao)
- JWT Access Token과 Refresh Token을 사용한 인증 관리

#### 회원가입
- 사용자가 이메일, 비밀번호, 닉네임을 입력하여 회원가입
- 이메일/닉네임 중복 여부 확인
- 회원가입 후 자동 로그인되어 Access Token 발급

#### 로그인
- 이메일 또는 닉네임과 비밀번호로 로그인
- 로그인 성공 시 Access Token과 Refresh Token 발급

#### Refresh Token 재발급
- Access Token 만료 시 Refresh Token을 제출하면 새로운 Access Token 발급
- Refresh Token Rotation(RTR) 적용: 이전 Refresh Token 폐기 후 새 토큰 발급
- 클라이언트는 Refresh Token을 HttpOnly 쿠키로 안전하게 관리

#### 로그아웃
- 현재 Access Token 무효화

#### 회원 탈퇴
- 로그인한 사용자는 본인 계정 삭제 가능

### 2. 유저 검색 

#### 개요
- 인증된 사용자는 닉네임 기반으로 다른 사용자를 검색 가능
- 검색 시 최근 검색 기록 저장 및 조회 가능

#### 검색 기능
- 닉네임 부분 검색 지원, 대소문자 구분 없음
- 검색 결과는 최근 검색 순으로 정렬
- 페이징 처리로 효율적인 데이터 반환

#### 검색 기록 관리
- 최근 검색 기록 저장, 조회, 삭제 가능
- 전체 검색 기록 삭제 가능

### 3. 게시글 검색
내부적으로 **Feed와 Explore** 2가지 검색 방식 제공

- **Feed 검색** : **Instagram의 피드**와 유사한 기능으로, 자신이 팔로우한 유저가 작성한 게시글을 최신 순으로 제공하는 기능
  - 로그인에 성공한 유저에 가장 먼저 제공되는 화면
  - **Pagination** 형식으로 구현되어 있으며 한 Page 당 6개의 게시글 제공
  - 자신이 팔로우하는 유저가 작성한 게시글이 없을 경우 *빈 피드* 화면 제공

- **Explore 검색** : **Instagram의 탐색** 탭과 유사한 기능으로, 자신을 포함한 전체 유저가 작성한 게시글이 최신 순으로 제공되는 기능
  - **무한 스크롤** 형식으로 구현되어 있으며, 사용자가 스크롤을 내릴 때마다 게시글이 추가로 제공
  - 마찬가지로 자신이 팔로우하는 유저가 작성한 게시글이 없을 경우 *빈 탐색* 화면이 제공


### 4. 게시글/댓글 업로드

- Instagram의 게시글 업로드 기능처럼 **사진을 여러 장 포함한 게시글**을 업로드할 수 있습니다.
게시글 양식은 글자 수 1000자 이하, 공백 제외 1자 이상이며 사진은 내부적으로 별도로 구현된 **AWS S3 presigned URL**을 통해 업로드됩니다.

- 추가 기능: 게시글 업로드 시 앨범을 선택&생성하여 게시글을 그룹화 가능

- 각 게시글에는 **댓글, 좋아요, 북마크** 기능 포함. **댓글**의 경우 게시글과 마찬가지로 글자 수 1000자 이하, 공백 제외 1자 이상으로 작성

    - **게시글과 댓글**의 수정, 삭제 기능도 제공

    - **좋아요와 북마크**는 토글 형식으로 구현되어 있어, 한 번의 요청으로 좋아요/북마크 추가 및 취소 가능

    - **북마크**는 유저 프로필 내 북마크 탭에서 확인 가능

    - **좋아요와 북마크**는 짧은 시간 내에 여러 번 요청이 들어올 수 있어, 이를 방지하기 위해 Transactional과 Pessimistic Lock을 활용하여 동시성 문제를 해결

### 5. 스토리 업로드
- Instagram의 스토리와 비슷한 기능으로, 사진 한 장을 스토리로 업로드 가능
- 상단 피드에는 팔로우한 사람들이 올린 24시간 내의 스토리가 보임
- 본인 스토리의 경우 조회수를 볼 수 있으며, 삭제 가능

### 6. 개인 프로필 

#### 조회
- 로그인한 사용자는 본인 및 다른 사용자의 프로필 정보를 조회 가능
- 프로필 화면에는 닉네임, bio, 게시글 등 포함

#### 수정
- 사용자는 본인 프로필을 수정 가능 (닉네임 등 공개 정보)

### 추가 기능 : 앨범
- 게시글 업로드 시, 기존 앨범 목록에서 선택하거나 새로운 앨범을 생성하여 게시글의 앨범 지정 가능
- 본인 게시글의 경우 앨범 수정 가능, 앨범에서 제외 가능
- 앨범 미지정 게시글의 경우 "앨범 없음"이라는 가상의 앨범 내에 존재
